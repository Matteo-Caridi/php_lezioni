| Cartella | Argomento |
|---|---|

| `DateTime_basic/` | Date e orari con `DateTime` |

| `height_order_function/` | Funzioni di ordine superiore |
| `sanitizeName_acronimGenerator/` | Pulizia di nomi e generatore di acronimi, con test |
| `case-study/` | Casi di studio: lista di attività da JSON/CSV, pulizia dei nomi |
| `oop_in_php/` | Programmazione a oggetti: lista di attività con la classe `Task` e i suoi test |
